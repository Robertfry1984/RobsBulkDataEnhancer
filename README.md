This is a simple (albiet complex) tool to work with large datasets and enhance them.

The tool itself is designed to be:
Something that you can copy/ paste bulk data into.
Set up a query to be used against each row of the data.
Select which column to use as reference.
Select which output column to append the answer to.
Select a response preference (E.g reply only in 1 or 2 words/ provide a sentance reponse/ provide a detailed explanation)

There is web search functionality selectable (although toggled off by default) whether you prefer LLM knowledge in response or wish to interrogate web for answers.
This tool is provided as-is.. 
Happy for contributors

Solely a workflow tool and not designed to be anything else except for something useful for day to day analysis and categorisation.

Stay safe out there :) Have run an initial security check - please check yourself before running too. 
I'm making this public due to not wishing to sell something vibecoded ;) Open licence - do what you wish with this.

To use; 
download.
Scan (for your own piece of mind).
Use the 'install.bat' to install dependancies.
Using the 'Launch.bat' to open the tool.
Copy your data you wish to enchance in to the table.
Set up your own API details for an LLM.
Add your question and how you want the answer to be appended in/ which columns to use.
Select how many rows you want to process.
Press 'Go'

Copy/ paste out into excel the AI outputs
